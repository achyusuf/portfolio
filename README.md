# Professional Portfolio

This project is a modern one-page portfolio website built with plain HTML, CSS, and JavaScript. It is ready to be published on GitHub Pages.

## What’s included
- Hero section with introduction and call-to-action buttons
- About section
- Projects section
- Contact section
- Responsive layout for desktop and mobile

## Run locally
Open the project folder in a browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000.

## Deploy to GitHub Pages
1. Push this repository to GitHub.
2. In the repository settings, open Pages.
3. Choose the branch to publish (usually main or master).
4. Select the root folder and save.

The site will be available at:

```text
https://<your-username>.github.io/<repository-name>/
```

## Customize content
Edit the following files:
- index.html for your name, bio, projects, and contact details
- styles.css for colors, fonts, and layout
- script.js for any small interactions
